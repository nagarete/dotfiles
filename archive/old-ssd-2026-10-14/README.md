Saved on 2026-10-14 from the Patriot P200 installation before its planned wipe.

The repository root preserves the old dotfiles working tree, including changes that had not been committed. This directory adds personal command wrappers, user services, older dotfiles backups, custom system services, hardware rules, and setup notes that lived outside that tree.

These files are an archive. They have not been installed into the new Omarchy system. Review each file before restoring it. The old username was `nagarete`; the new home is `/home/nagarete-arch-5`. Absolute paths and symlink targets may need changes. Old `/dev/sda` and `/dev/sdb` references must be checked against the current disk layout.

SSH keys and Infisical secret backups were copied privately to the new home and are not part of this repository. OpenCode's service password and local session/task state remain local. Downloadable executable binaries were omitted; small personal scripts and symlinks were retained.
